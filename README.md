## Name

held-moth-bark

## Purpose

A tiny Node 22 program that writes a calming still-life sentence to `entry.txt`. The output directory defaults to `./output` and can be changed with `MAKEFUN_OUTPUT_DIR`.

## Run

```sh
node main.ts
```
